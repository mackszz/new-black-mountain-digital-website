# NEW Black Mountain Digital Website

## Project Brief

Build a modern, high-converting B2B technology website for **Black Mountain Digital**, a Canadian technology solutions provider founded in 1996. **Positioning: full-stack technology partner.** Black Mountain helps businesses grow with technology that actually works, across five equally-weighted pillars — AI Services, Security, Voice, Connectivity, and Data Cabling. AI-driven automation and UCaaS are flagship strengths and should get prominent placement, but they are not the whole story — Security, Connectivity, and Data Cabling are presented as equally credible, fully-fledged service lines, not add-ons. Sweet spot audience: SMBs and mid-market Canadian businesses that want enterprise-level results without enterprise-level complexity, ideally as a single accountable partner rather than juggling multiple vendors. The brand feels established, trustworthy, and vendor-agnostic — not a flashy startup.

**Brand voice — we are:** Bold · Precise · Elevated · Trustworthy
**Brand voice — we are not:** Flashy · Complicated · Trendy · Generic

Write every headline, body paragraph, and CTA to match this voice. Avoid generic SaaS-marketing clichés ("revolutionize," "seamless," "cutting-edge," "unlock," "supercharge") — replace with concrete, specific, confident language. Sentences should be precise, not padded. No exclamation points. No forced enthusiasm.

## Brand System

### Logo
- Files: `BMD_Logo_Black.png` (light backgrounds), `BMD_Logo_White.png` (dark backgrounds/footer)
- Clear space: minimum padding on all sides equal to the height of the mountain peak icon
- Minimum display size: 32px height
- Never rotate, distort, recolor, or add effects (shadows, gradients, outlines) to the logo

### Colour Palette

| Name       | HEX     | Usage                          |
|------------|---------|---------------------------------|
| Black      | #1A1A1A | Primary text, dark surfaces    |
| Charcoal   | #2E2E2E | Secondary dark, backgrounds    |
| Slate      | #525A62 | Body text, muted elements      |
| Peak Blue  | #6B8FA0 | Accent, highlights, CTAs       |
| Stone      | #ECEAE7 | Light backgrounds, dividers    |
| White      | #FAFAFA | Primary background             |

Use Peak Blue deliberately and sparingly — for CTAs, links, icons, and key highlights — not as a dominant fill colour. Black/Charcoal/Slate carry most of the type and dark UI. Stone and White carry the backgrounds. This is a restrained, editorial palette, not a bright startup palette — avoid adding any colours outside this table.

### Typography
- **Display / Headings:** Space Grotesk — Bold (700) for H1/Display, Semibold (600) for H2 and section heads
- **Body:** Inter — Regular (400) for paragraph copy, Medium (500) for UI elements/emphasis
- **Mono:** System monospace — for any code, data points, or technical labels (e.g., uptime %, spec sheets)
- Both are Google Fonts: Space Grotesk, Inter

**Type scale:**

| Level    | Font           | Size / Weight        |
|----------|----------------|-----------------------|
| Display  | Space Grotesk  | 60–96px / Bold        |
| H1       | Space Grotesk  | 40–56px / Bold        |
| H2       | Space Grotesk  | 28–32px / Semibold    |

## SEO Requirements (non-negotiable — this is the #1 priority)

The current site has auto-generated placeholder meta descriptions on every page ("This page was automatically generated by WPConvert") — this must not happen again. For **every page**, generate:

- A unique, keyword-relevant `<title>` (55–60 characters) in the pattern: `[Primary Keyword] | Black Mountain Digital`
- A unique meta description (140–155 characters) that includes the primary service keyword + a value proposition + implicit CTA
- One clear H1 per page matching search intent (not just the brand tagline)
- Logical H2/H3 hierarchy — no skipped levels, no headings used purely for visual styling
- Descriptive alt text on every image (not "team collaboration" — describe what's actually happening and tie to the service)
- Internal links between related service pages (e.g., SD-WAN page links to Business Broadband and Network Security)
- FAQ section on every service page (3–5 questions) written in natural-language, long-tail search phrasing — structure this content so it could later support FAQ schema
- Include Ontario/Canada geographic signals naturally in copy where relevant (they're a Canadian provider — this site currently has zero local SEO signal despite that being a differentiator)

Target keyword themes to seed into copy (don't keyword-stuff — write naturally):
- "managed IT services Ontario/Canada", "business VoIP provider Canada", "AI customer service automation", "AI receptionist for small business", "SD-WAN provider", "network cyber security for business", "structured cabling contractor", "wholesale telecom services"

## Site Structure & Page-by-Page Content Direction

### 1. Homepage
Replace the generic "Technology That Drives Business Forward" hero with something specific to what they actually do and for whom (SMB/mid-market Canadian businesses). Structure:
- Hero: specific value prop + primary CTA ("Talk to an Expert") + secondary CTA ("Explore Services")
- Trust bar: 500+ projects / 200+ clients / 98% satisfaction / 24/7 support / founded 1996 — pull this up from the About page, it's currently buried
- "Why Black Mountain" section: vendor-agnostic + 30-year track record + long-term partnership — this is their real differentiator and it's currently hidden on the About page instead of the homepage
- Services grid (5 pillars, short benefit-led descriptions, each linking to its page)
- Social proof section: **add placeholder testimonial cards** (3 client quotes, generic industry roles, clearly marked as placeholder copy for the client to replace with real quotes)
- Final CTA band

### 2. About
Keep the existing structure (Story / Mission / Vision / Values / Why Choose Us / Stats) — it's the strongest content on the current site — but tighten the copy and fix the grammar error ("began it's journey" → "began its journey"). Add a short leadership/team section if photos are available (placeholder if not).

### 3–4. AI Services (AI Customer Service Rep, AI Receptionist)
Keep the benefit-led structure from the current AI Customer Service Rep page (it's the best-written page on the site) as the template for both: intro + stat callouts → features grid → enterprise capabilities grid → FAQ → CTA. Make sure AI Receptionist gets equally specific copy, not a reskin of the CSR page.

### 5–6. Security (Network & Cyber Security, Physical Security)
Add concrete specifics currently missing: what's actually included (firewall management, endpoint protection, threat monitoring, access control, video surveillance, etc.), compliance angle (PIPEDA for Canadian businesses), and an FAQ addressing common buyer objections ("do I need this if I already have antivirus," "how fast can this be deployed").

### 7–8. Voice (UCaaS, CX)
Clarify the distinction between these two (currently unclear from nav alone) — UCaaS as the platform/infrastructure, CX as the customer-experience/contact-center layer. Add integration/compatibility language (works with existing phone systems, CRM, etc.).

### 9–10. Connectivity (Business Broadband, SD-WAN)
Add technical credibility markers: uptime SLA numbers, redundancy/failover explanation, multi-site management use case for SD-WAN specifically.

### 11. Data Cabling
Currently a single nav link with presumably thin content — build out: services offered (structured cabling, fiber installation, cable management, testing/certification), typical project types (office buildouts, data centers, retrofits).

### 12. Contact
Referenced throughout via CTAs but not detailed here — build a proper contact page centered on a **contact form as the primary CTA** (not a bare mailto link), with phone numbers and email listed alongside as secondary options. Form fields: name, company, email, phone, service interested in (dropdown matching the 5 service pillars), message. Also include: both phone numbers, email as a fallback, and (if applicable) office address/hours for local SEO. Use a real `<form>` with client-side validation, not just a mailto: href — this improves mobile conversion, lead quality, and lets submissions be tracked as an analytics goal.

## Layout & UX Direction

- Sticky header with the existing mega-menu grouping (AI Services / Security / Voice / Connectivity / Data Cabling / About) — keep this, it's a reasonable IA
- Every page ends in a consistent CTA band (not just "Talk to an Expert" repeated identically — vary the copy per page to match that page's specific value prop)
- Footer: keep the current sitemap structure, add social links (if available) and a privacy policy / terms link (currently missing — needed for a legitimate B2B site)
- Mobile-first responsive layout, generous whitespace, no dense walls of text — break long sections into scannable cards/grids as the current site mostly does
- Replace generic stock photography with more specific imagery direction: real-feeling office/network/security imagery rather than generic "team high-fiving" stock shots (use placeholder images with clear alt text describing what should eventually go there)
- Add breadcrumbs on service pages (helps both UX and SEO)
